ATHENA DataArt palette attribution
==================================

ATHENA's native DataArt renderer does not depend on or distribute the
Matplotlib Python runtime. The packed RGB tables in
src/ATHENA/Data/data_art_palettes.inc were generated by sampling selected
Matplotlib 3.10.9 colormaps at 256 entries and converting those samples to
0xRRGGBB C++ constants.

This is the only Matplotlib-derived material distributed by DataArt. The
Gist/Yorick notice additionally applies to the sampled Gist/Yorick colormaps
used by DataArt (including gist_earth and ocean). Licenses bundled with
Matplotlib for unrelated fonts, Qhull, GUI helpers, test data, and other
components are intentionally omitted.

Changes from Matplotlib: colormap outputs were sampled at 256 positions and
stored as packed native C++ RGB constants; no Matplotlib runtime code is used.
